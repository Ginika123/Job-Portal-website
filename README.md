# 💼 CareerConnect – React Job Portal

CareerConnect is a modern and responsive job portal built with React.js. It allows users to browse job opportunities, search for jobs, save their favorite jobs, and view detailed job information. The application fetches real-time job listings from an external API and provides a clean, user-friendly interface across desktop, tablet, and mobile devices.

---

 Features

- 🔍 Search for jobs by title
- 🌍 Browse remote job opportunities
- 📄 View detailed job descriptions
- ❤️ Save favorite jobs using Local Storage
- 🏢 Companies page
- ℹ️ About page
- 📞 Contact page
- 🔐 Login and Register pages (UI)
- 📱 Fully responsive design
- ✨ Smooth animations with Framer Motion
- ⚡ API integration for live job listings

---

🛠️ Built With

- React.js
- React Router DOM
- CSS3
- Framer Motion
- React Icons
- Local Storage
- Remotive Jobs API
